# Релиз v0.6.2 — Zero-Root Standalone NPU Engine & Modern Material 3 UI

Крупное обновление мобильного приложения для автономной генерации SDXL на чипах Qualcomm Snapdragon 8 Elite (SM8750 / Hexagon V79).

---

## 🚀 Ключевые изменения

### 1. Настоящий Zero-Root инференс (без запросов Magisk / root)
- **Устранена ошибка `Permission denied`**: Ранее при наличии бинарника `su` на устройстве приложение форсировало запуск через `su --mount-master`, что вызывало сбой, если приложению не были выданы root-права в Magisk.
- **Чистый Userspace**: Нативный C-движок инференса теперь запускается через стандартный `/system/bin/sh` в пространстве пользователя. Root более не требуется для генерации.

### 2. Бандлинг Qualcomm FastRPC `libcdsprpc.so` (Исправление ошибок 4000 и 14001)
- **Устранена ошибка `loadRemoteSymbols failed with err 4000` / `Failed to create transport for device: 4000`**: В предыдущих версиях библиотека `libcdsprpc.so` не была упакована в APK, из-за чего QNN не мог инициализировать FastRPC транспорт к Hexagon cDSP в изолированном Android linker namespace.
- Теперь `libcdsprpc.so` упакована в payload APK и загружается нативным движком с флагом `RTLD_GLOBAL`, экспортируя все символы FastRPC (`remote_handle_open`, `rpcmem_alloc`) в глобальную таблицу процесса до поднятия бэкенда QNN.

### 3. Progressive CFG dCache включён по умолчанию (~7.0с на генерацию)
- Чекбокс **Progressive CFG (dCache ~7с)** теперь активен по умолчанию.
- Алгоритм выполняет первые 5 шагов в полноценном 2-pass режиме, а оставшиеся 3 шага — через кэширование дельты безусловного шума. Время генерации сокращено до **~7.0 секунд** без видимой потери качества.

### 4. Полный редизайн интерфейса (Modern Material 3 Dark)
- Приложение избавилось от устаревшего Holo/Lollipop стиля и переведено на стильную тёмную тему Material 3 (глубокий чёрный `#0B0D11`, карточки `#151821`, акцент `#6366F1`).
- **Быстрые пресеты разрешений**: Добавлены компактные чипы быстрого выбора популярных пропорций SDXL:
  - `1:1 (1024×1024)`
  - `2:3 (832×1216)`
  - `3:2 (1216×832)`
  - `3:4 (768×1024)`
  - `HD (1344×1728)`
- **Кнопка рандомизации Seed (🎲)**: Генерация случайного seed в один тап.
- **Карточный интерфейс**: Параметры, промпт и результат разделены на аккуратные карточки со скруглёнными углами (18dp).
- **Современная кнопка генерации**: Крупная пилюля с акцентным цветом и плавной анимацией нажатия.

### 5. Единственный файл в релизе
- В соответствии с правилами опубликован ровно один APK-файл: `sdxl-npu-v0.6.2.apk`.

Скачайте `sdxl-npu-v0.6.2.apk` из вложений ниже и установите на телефон.
При первом запуске приложение автоматически распакует обновлённый бандл компонентов.
