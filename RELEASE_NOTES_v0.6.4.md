# SDXL NPU Engine — Release v0.6.4

Автономный нативный инференс SDXL на чипах Qualcomm Snapdragon 8 Elite (SM8750 / Hexagon V79).

---

## Что нового в v0.6.4

### 1. Окончательное решение проблемы FastRPC / DSP (True Zero-Root Linker Isolation Fix)
- **Корень проблемы:** В Android SELinux и bionic dynamic linker (`/linkerconfig/ld.config.txt`) любой исполняемый файл, запускаемый из приватного каталога приложения (`/data/user/0/...`), принудительно изолируется в пространстве имён `[system]` (`namespace.default.isolated = true`). В этой песочнице Android запрещает загрузку вендорных библиотек FastRPC (`vendor.qti.hardware.dsp@1.0.so`), из-за чего cDSP transport падал с кодами `4000` и `14001`.
- **Архитектурное решение:** 
  - В правилах Android Linker путь `/data/local/tmp` явно зарегистрирован как `dir.unrestricted` (`namespace.default.isolated = false`, `search.paths += /vendor/${LIB}`).
  - При запуске приложение без root-прав автоматически разворачивает нативный C-движок и библиотеки в `/data/local/tmp/sdxl_app_engine/`. Каталог `/data/local/tmp` имеет права `0777`, поэтому непривилегированный процесс приложения (`u0_a...`) свободно создает файлы и запускает нативный бинарник.
  - Нативный бинарник запускается в пространстве `[unrestricted]`, получая прямой доступ к аппаратному FastRPC cDSP транспорту `/dev/fastrpc-cdsp` и драйверам Hexagon DSP.
  - **Результат:** 100% стабильная аппаратная генерация без root-прав, без Magisk/KernelSU и без Termux!

### 2. Верификация на устройстве
- Протестирован полный сквозной цикл генерации `1024×1024` через UI приложения:
  - CLIP-L: 142 мс
  - UNet (Progressive CFG 8 шагов с dCache): 10.59 с
  - VAE Decoder: 2.32 с
  - Полное время генерации: **~20.0 с** (холодный старт с загрузкой 2.5 ГБ контекста UNet в память Hexagon).

### 3. Строгий технический дизайн и динамический выбор LoRA
- Включены все наработки v0.6.3:
  - Строгая индустриальная тёмная тема (`#08090C`).
  - Progressive CFG (dCache) активен по умолчанию.
  - Динамический селектор LoRA и ползунок силы эффекта (0.00 – 1.50).
- Строго единственный файл релиза: `sdxl-npu-v0.6.4.apk`.
