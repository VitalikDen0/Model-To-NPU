# SDXL NPU Engine — Release v0.6.3

Автономный нативный инференс SDXL на чипах Qualcomm Snapdragon 8 Elite (SM8750 / Hexagon V79).

---

## Что нового в v0.6.3

### 1. Zero-Root FastRPC cDSP Fix (Ошибки 4000 и 14001)
- **Причина проблемы**: При запуске из непривилегированного Android-процесса библиотека cDSP FastRPC (`libcdsprpc.so`) не загружалась глобально, а переменная окружения `ADSP_LIBRARY_PATH` не была экспортирована внутри процесса, из-за чего FastRPC не мог найти `libQnnHtpV79Skel.so`. Это приводило к ошибкам `loadRemoteSymbols failed with err 4000` и срыву создания контекста QNN `14001`.
- **Решение**: 
  - Функция `setup_dsp_environment()` в нативном C-движке автоматически настраивает `ADSP_LIBRARY_PATH` и `LD_LIBRARY_PATH`.
  - Добавлен аргумент `--rpc_lib <path>`, позволяющий приложению передавать точный путь к `libcdsprpc.so`.
  - Библиотека `libcdsprpc.so` загружается с флагом `RTLD_GLOBAL` перед инициализацией бэкенда QNN.
  - На Snapdragon 8 Elite инференс теперь стабильно поднимается из обычного приложения **без root-прав**!

### 2. Динамическая поддержка LoRA
- В C-движок добавлена поддержка аргументов `--lora <slot|path>` и `--lora_scale <float>`.
- Автоматический поиск скомпилированных контекстов UNet в:
  - `<base_dir>/loras/`
  - `<base_dir>/context/lora_slots/<slot>/`
  - `<base_dir>/context/<slot>/`
- В UI добавлен выпадающий список обнаруженных LoRA и слайдер силы влияния LoRA (от 0.00 до 1.50).

### 3. Progressive CFG (dCache) по умолчанию
- Чекбокс Progressive CFG теперь включён по умолчанию.
- Режим 5 full CFG + 3 delta-cache шагов обеспечивает ускорение сэмплирования в ~1.6× без потери детализации.

### 4. Строгий технический тёмный интерфейс
- Убраны несерьёзные эмодзи и яркий зелёный бейдж `~7.0s`.
- Реализована сдержанная индустриальная тёмная тема:
  - Глубокий матовый фон: `#08090C`
  - Поверхности карточек: `#111318`
  - Тонкие строгие границы: `#222733`
  - Акцент: тактический циан `#38BDF8`
- Строгие радиусы скругления (8–10dp), чёткие заголовки разделов в верхнем регистре (`ПРОМПТ`, `ПАРАМЕТРЫ СЭМПЛИРОВАНИЯ`, `ФОРМАТ И РАЗРЕШЕНИЕ`, `LORA АДАПТЕР`).

### 5. Единый релизный артефакт
- В соответствии с правилом исключения дубликатов публикуется строго один файл: `sdxl-npu-v0.6.3.apk`.

---

## Установка
1. Скачайте `sdxl-npu-v0.6.3.apk` и установите на телефон.
2. При первом запуске приложение автоматически обновит внутренний payload (`native-bundle-v0.6.3`).
3. Root-доступ для генерации не требуется.
